# learn-hermes-ai-with-phoebe

An 8-session interactive course on Nous Research's Hermes - the open-weights AI you can download, steer, and own. One running build across the course: your own private AI assistant, from first hello to fully autonomous.

**Live site:** https://phoebefu6.github.io/learn-hermes-ai-with-phoebe/

## The arc

| # | Session | Difficulty |
|---|---------|------------|
| 1 | Meet Hermes: the AI that answers to you | easiest |
| 2 | Get it on your machine, properly | easy |
| 3 | Steer it: system prompts and personas | medium |
| 4 | Think when it matters: hybrid reasoning | medium |
| 5 | Structured output: JSON that validates | hands-on |
| 6 | Tool calling: give it hands | hands-on |
| 7 | Hermes as a service: APIs, pricing, licenses | medium |
| 8 | Go autonomous: Hermes Agent | capstone |

Plus 5 self-paced deep dives: how Hermes is made, the Psyche decentralized-training story, production serving, fine-tuning, and reading RefusalBench critically.

## Format

- 45 minutes per session: 3 welcome / ~15 concepts / ~22 build-along / 5 Q&A
- Every session upgrades the same artifact: your private AI assistant
- Concepts split into Live (presented) and Self-study (full depth after class)
- Every session ends with homework, a 3-question quiz, sources covered, and a cheat sheet
- Presenter run-of-show notes live in `materials/`

## Sources

Taught from primary sources: the [Nous Research releases timeline](https://nousresearch.com/releases), the [Hermes 4 technical report](https://arxiv.org/abs/2508.18255), official HuggingFace model cards, the Hermes Agent docs, and the Ollama / LM Studio / OpenRouter listings. Coverage map and verification notes: `materials/official-course-map.md`.

Hermes moves fast - re-verify pricing and the newest model against the releases page before delivering a session.
